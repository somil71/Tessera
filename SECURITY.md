# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within Tessera, please report it responsibly:
- Email security findings to the maintainers or open a private security advisory on GitHub.
- Do not disclose security issues publicly until a fix has been released.
