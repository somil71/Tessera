# Amendment 6: independent SAR shoreline holdout

Frozen 2026-11-25 **before model download or operator-graph inspection**. The earlier SCUNet, FraXet, and FTP-B3 holdouts failed compatibility preflight and are exposed development material. This amendment designates a newly authored external model and exact evaluation inputs. A failure remains a failed holdout; later compatibility fixes cannot turn it into unseen evidence.

The [public model card](https://huggingface.co/2320sharon/SAR_3_band_model) describes a Sentinel-1 land/water U-Net with a ResNet-50 encoder, dynamic FP32 NCHW height and width, and two outputs: two-channel logits plus a derived water-probability map. It requires dimensions divisible by 32. The v1 contract accepts one raster output, so the predeclared projection in `tests/performance/prepare_sar3_holdout.py` keeps the ancestor graph of the `logits` output and removes the probability output and nodes used only by it. It does not change any node that contributes to logits. This projection is fixed before looking at the ONNX graph; the script must fail if the declared `logits` output is absent.

- Both automatic and baseline schedules use this Windows CPU, a hard 1 GiB job committed-memory cap, and at most two inference threads. Record raw outer and execution peaks as well as sampled private commitment. Any unexplained raw peak over cap prevents a clear pass under [amendment 2](evaluation-amendment-2.md).
- If preflight supports the projected graph, freeze manual candidates before automatic inference. Permit four hours of baseline tuning per input-machine pair, retain all attempts, then alternate one first and five repeat pairs. A clear pass requires every run to meet correctness and memory limits and each repeated median automatic wall time to be ≤ 1.25× the tuned baseline. > 1.5× on most pairs is a performance failure; intermediate results are inconclusive.

The model card says preprocessing is external to the graph. These synthetic normalized rasters deliberately isolate numerical scheduling. A subsequent independent user trial must use a matching real SAR composite and declared bandwise normalization. This amendment alone cannot establish map accuracy, independent adoption, or a second-machine claim.
