# Amendment 7: independent Deforestation U-Net holdout

Frozen 2026-11-25 **before model download or operator-graph inspection**. The earlier SCUNet, FraXet, FTP-B3, and SAR shoreline holdouts failed compatibility preflight and are exposed development material. This amendment designates a newly authored external remote-sensing model and exact evaluation inputs. A failure remains a failed holdout; later compatibility fixes cannot turn it into unseen evidence.

The [public model card](https://huggingface.co/ItsArca/deforestation-unet-onnx) describes an ONNX-exported U-Net segmentation model intended for deforestation detection on Sentinel-2 satellite imagery tiles. The model accepts a 10-band FP32 NCHW tile and outputs 3-class class logits (Non-forest, Forest, Deforested). The declared native input shape is `[1, 10, 512, 512]` and output shape is `[1, 3, 512, 512]`.

- Source repository: `ItsArca/deforestation-unet-onnx`.
- Source revision: `e16cba63ca6d426105bc8ee6aed64e89a43b3e5e`.
- Source URL: `https://huggingface.co/ItsArca/deforestation-unet-onnx/resolve/e16cba63ca6d426105bc8ee6aed64e89a43b3e5e/unet_deforestation.onnx`.
- Reported size: 7,717,953 bytes.
- Local model: `models/holdout/deforestation-unet.onnx` (7,717,953 bytes; SHA-256 `a6c0329aaef4b0758d90cbfd80164bb045b8d3dcfbf82072b96d1d0566e96e8a`).
- Input: `data/holdout/deforestation/deforestation-512.tif` (10,489,262 bytes; SHA-256 `ef66fc99aff2a1d3961caa7f42f6136877c4106c9133c0a0e41f626f13a2c0e1`), generated by `tests/performance/prepare_deforestation_holdout.py` with NumPy seed 8307. It is a deterministic 10-band FP32 normalized synthetic raster with EPSG:32643, 10 m pixels, and `from_origin(500000, 2000000, 10, 10)`. It tests execution semantics, not map accuracy.
- Unsplit ONNX Runtime on this fitting 512×512 input is the raw-logit reference; comparison checks every pixel, georeferencing, maximum absolute error ≤ `1e-4`, and eligible relative error ≤ `1e-3` where reference magnitude ≥ `1e-3`.
- Both automatic and baseline schedules use this Windows CPU, a hard 1 GiB (1,073,741,824 bytes) Job Object committed-memory cap, and at most two inference threads. Record raw outer and execution peaks as well as sampled private commitment. Any unexplained raw peak over cap prevents a clear pass under [amendment 2](evaluation-amendment-2.md).
- If preflight supports the model graph, freeze manual candidates in `evaluation/deforestation-manual-candidates.json` before automatic inference. Permit four hours of baseline tuning, retain all attempts, then alternate one first and five repeat pairs. A clear pass requires every run to meet correctness and memory limits and the repeated median automatic wall time to be ≤ 1.25× the tuned baseline. > 1.5× is a performance failure; intermediate results are inconclusive.

The model card specifies that the 10 bands correspond to Sentinel-2 spectral bands. These synthetic normalized rasters isolate numerical scheduling. This amendment alone cannot establish real-world map accuracy, independent adoption, or a second-machine claim.
